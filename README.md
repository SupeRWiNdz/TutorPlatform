# Инструкция по развёртыванию

## Требования
1. [Docker](https://www.docker.com/get-started)
2. [Docker Compose](https://docs.docker.com/compose/install/) (входит в состав Docker Desktop для Windows/Mac)

## Установка и запуск
1. Клонируйте репозиторий и перейдите в папку проекта:
```
   git clone https://github.com/SupeRWiNdz/TutorPlatform
   cd TutorPlatform
```
2. Запустите сборку и все сервисы:
```
   docker-compose up --build
```
В процессе будут собраны образы для фронтенда и бэкенда, поднята база данных PostgreSQL и применён файл инициализации init.sql (создание таблиц, функций и тестовых данных).

3. Дождитесь, пока все контейнеры запустятся. Когда в логах появится сообщение о готовности, приложение будет доступно по адресам:

* Фронтенд — http://localhost:4200
* Бэкенд — http://localhost:3000
* База данных — localhost:5432 (пользователь postgres, пароль 123123, БД tutor_platform)

Важно: При открытии фронтенда в браузере убедитесь, что вы используете протокол HTTP, а не HTTPS. Браузеры иногда автоматически перенаправляют на HTTPS, что может вызвать ошибку SSL. Введите адрес вручную: http://localhost:4200.

## Остановка приложения

Чтобы остановить контейнеры, нажмите Ctrl+C в терминале или выполните:
```
docker-compose down
```
